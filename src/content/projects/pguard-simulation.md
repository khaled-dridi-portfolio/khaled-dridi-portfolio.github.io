A high-fidelity virtual simulation for the PGuard wheeled robot that showcases automatic navigation through challenging environments using advanced sensors and cameras. The simulation demonstrates the robot's ability to report statistics and surveil open space areas such as airports, government facilities, and private installations.

Built with Unreal Engine 5, the project features 2 backend servers, a load distributor, and a centralized Flutter dashboard. It was developed in collaboration with Enova Robotics in Tunisia during a 5-month internship, and won first place best project award at university among all senior year classes, marking my fourth consecutive year achieving first place.

## What I built

- Created a 3D Unreal Engine simulation for autonomous robot patrol on user-uploaded maps.
- Implemented realistic sensor behavior and navigation control systems.
- Developed OpenCV-based fire, human, and face detection for the robot's onboard camera.
