# Project assets (raw material)

> **Quickest way:** paste files into `inbox/` and tell Claude which project they're for.
> Claude sorts them into the right place.

Drop everything for a project here, in its own folder. Nothing in this folder is published or
pushed to GitHub (it is git-ignored, except this README) — it's the raw material. When we go
through a project together, I pick the files, optimise them and copy them into the site.

## One folder per project

```
project-assets/
  pgard-simulator/
    images/     screenshots, logo/icon, cover — any size, PNG or JPG
    videos/     gameplay / demo recordings — any length (long ones go to YouTube)
    notes.md    anything you remember: role, dates, tech, client, links, story
```

Folders for the four projects from your CV already exist. For any other project (freelance work,
other games, websites, apps), copy `_template/` and rename it — use lowercase-with-dashes,
e.g. `space-shooter`, because the folder name becomes the project's web address
(`/projects/space-shooter/`).

## What helps most

- **Logo / icon** — square, transparent background if you have it (`logo.png`).
- **Cover** — one strong 16:9 screenshot (`cover.png`).
- **Screenshots** — 3–8 of the best moments.
- **Video** — a gameplay/demo recording. A short 5–10 s clip of the best moment is great for the
  card hover preview; the full video can go on YouTube.
- **Links** — live site, itch.io, store page, GitHub, YouTube (put them in `notes.md`).
- Don't worry about file names, sizes or formats — I'll sort that out.
