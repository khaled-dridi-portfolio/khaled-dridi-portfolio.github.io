# Inbox — paste files here

Drop anything you want on the site into this folder: images, logos, screenshots, videos,
PDFs, notes. Any name, size or format is fine, and sub-folders are fine too.

Then tell Claude something like: "I put new files in the inbox — they're for Plavox."
Claude will look at them, compress what needs compressing, copy the web versions into the site,
and move the originals into `project-assets/<project>/` so the inbox is empty again.

Nothing in here is published or pushed to GitHub.

A short note helps (a `notes.md` or `.txt` in the folder is enough): which project the files
are for, and anything you want said about them (e.g. "this is the main menu", "use as the cover").
